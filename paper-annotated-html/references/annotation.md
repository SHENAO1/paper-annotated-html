# 批注与总览写法

批注是这个页面最有价值的部分。读者已经能读原文和译文，批注要给出他们**自己一时看不出来的东西**：这段在整条论证链里起什么作用，用了什么技巧，哪里站不住。

## 1. 先读完全文，再写批注

逐段批注之前，先通读全文，在 `meta.json` 里写好论证骨架和核心主张的草稿。只有知道终点在哪，才能说清每一段处在论证链的哪个位置。写完所有段落后，再回头修订总览。

## 2. 段落批注四个字段

### func 段落功能（必填，≤12 字）

用动宾短语或名词短语给这段贴一个标签。例子：

- 引出问题、提出研究缺口、界定概念、交代背景
- 陈述假设、给出核心主张、说明方法、描述实验设置
- 报告结果、举例佐证、比较方案、预设反驳、回应异议
- 承认局限、过渡衔接、总结全文、展望未来工作

可以组合使用，比如"摘要：动机→方案→结果""由应用推导指标"。

### role 逻辑角色（必填，1–2 句）

说明这段**和其他段落的关系**：支撑哪个主张，为哪一节做铺垫，回应哪个问题，在论证链中处在哪一环。

- ✓ "把引言的定性需求转化为表 1 的定量指标，是‘需求→设计’的枢纽段。"
- ✗ "本段介绍了设计要求。"（这只是复述内容，没有说明它和其他部分的关系）

### craft 论证技巧（建议写）

指出**这一段具体用了什么手法**，而且要落在这段的内容上。常见的有：

- 用具体数字代替形容词；
- 设计目标和实测值并列；
- 用排除法给自己的方案腾出位置；
- 先让步再限定；
- 下定义时顺带缩小讨论范围；
- 用类比降低理解门槛；
- 用三角互证增强效度。

- ✓ "用‘先分层抽样、再按学校加权’一句话交代样本如何代表总体，后文所有推断都建立在这个设计上。"
- ✗ "逻辑清晰，论证有力。"（放到哪一段都成立，等于什么都没说）

### gap 潜在漏洞（有就写，不硬凑）

写**具体的**弱点，并说明它为什么会削弱论证。可以从这些方面查：

- 证据只来自引文，没有本文的数据；
- 结论比证据说得更强（相关说成因果，"初步"说成"证明"）；
- 缺少对照组或基线，比较的对象不公平；
- 样本或语料的代表性有问题，或者结论推广过度；
- 指标和主张对不上（比如声称"快"，实测却没达标）；
- 关键假设没有交代；
- 把难点划出了本文的讨论范围；
- 术语前后用法不一致。

没有明显漏洞的段落可以不写 gap，但 craft 和 gap 至少要写一项。批注总数里应当有相当一部分带 gap，精读的价值大半在这里。

批评要公允：先确认作者在别处没有回应过这个问题，再说它是漏洞。如果作者在后文回应了，就在 gap 里写"……（作者在 S8.P2 部分回应）"。

### stage 骨架阶段（必填）

从 `problem`、`claim`、`evidence`、`rebuttal`、`conclusion` 中选一个，表示这段主要服务于骨架的哪一步。卡片上显示的名称随体裁变化，比如 design 体裁下 `evidence` 显示为"设计与验证"。方法和设计段落归入 `evidence`。

## 3. 图、表、公式

- **图注**一律翻译。关键结果图（直接支撑主张的那几张）要写 note，说明它证明了什么，有没有值得注意的地方，比如坐标轴截断、缺误差棒或缺对照条件。
- **表格**：表题一律翻译。数据表建议用 `table` 字段转写成 HTML 表，表头译成中文，数值照原文写；需要逐格核对截图。表格很大或结构复杂时可以不转写，只保留截图。
- **公式**：在 `latex` 字段写出 LaTeX，必须对照页面图逐个符号核对。`zh` 可以用一句话说明公式的物理含义或作用。

## 4. 节标题与小结

- 每个 `S{n}.json` 都要写 `title_zh`。
- `summary` 可选。较长的节建议写一两句话，说明这一节在全文中的作用。

## 5. 论证总览（meta.json → overview）

| 部分 | 要求 |
|---|---|
| skeleton 五步 | 每步 1–3 句，写**这篇论文的具体内容**，不要写"作者提出了问题"这类空话；每步都附上 refs |
| thesis | 一句话说清作者的核心主张，最好不超过 80 字，包含"主张什么 + 凭什么"；`en` 可以放原文中最接近的一句 |
| strongest | 论证最强的一处：为什么强（证据直接、设计严谨、反驳充分），附 refs |
| weakest | 论证最弱的一处：具体哪一步跳了、缺什么证据，附 refs。要指向实质问题，而不是"样本可以更大"这类放之四海皆准的话 |
| claims | 3–6 条主要主张，每条写明证据和强度。strong：本文有直接数据或严密推理；medium：有支撑，但间接或不完整；weak：只有引文、推测或个例 |

## 6. 自检

写完一节后问自己：

1. 只看这一节的批注，能不能复述这一节的论证？
2. 有没有一句批注，换到别的论文里照样成立？有就重写。
3. gap 是不是都有具体所指，有没有冤枉作者？
4. stage 的分布是否合理？引言多半是 problem，结果节多半是 evidence。
